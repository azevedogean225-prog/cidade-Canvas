# 🏦 Future Account City

> Uma experiência interativa de educação financeira desenvolvida com JavaScript e HTML5 Canvas.

## 🎯 Sobre o projeto

O **Future Account City** é um projeto que transforma conceitos de organização financeira em uma experiência visual e interativa.

A proposta é colocar o usuário dentro de uma pequena cidade virtual, onde ele pode interagir com um banco, criar objetivos financeiros, definir quanto deseja guardar e acompanhar sua evolução.

O projeto também foi pensado para adaptar a experiência ao nível de conhecimento financeiro do usuário, tornando o aprendizado mais acessível e gradual.

## ✨ Funcionalidades

* 🏙️ Cidade virtual desenvolvida em Canvas
* 🏦 Banco virtual interativo
* 👤 Cadastro do usuário
* 🧠 Seleção do nível de conhecimento financeiro
* 🎯 Criação de objetivos financeiros
* 💰 Definição do valor da meta
* 📅 Definição de prazo em meses ou anos
* 💵 Definição de aporte mensal
* 📊 Acompanhamento do progresso da meta
* 🪙 Animação de moedas durante os depósitos
* 🔊 Efeito sonoro para depósitos
* 🏆 Sistema de conquistas
* 👩‍💼 Atendimento virtual dentro do banco
* 📚 Estrutura preparada para conteúdos de educação financeira

## 🎮 Como funciona

O fluxo principal da aplicação foi pensado para acompanhar o usuário desde sua entrada na cidade até o planejamento de uma meta financeira.

```text
🏙️ Cidade
   ↓
👋 Boas-vindas
   ↓
👤 Cadastro
   ↓
🧠 Nível de conhecimento financeiro
   ↓
🏦 Menu do banco
   ↓
🎯 Criar objetivo
   ↓
💰 Definir valor da meta
   ↓
📅 Definir prazo
   ↓
💵 Definir aporte mensal
   ↓
📊 Acompanhar progresso
```

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/azevedogean225-prog/cidade-Canvas.git
```

### 2. Acesse a pasta

```bash
cd cidade-Canvas
```

### 3. Execute o projeto

Abra o arquivo `index.html` em um navegador.

Também é possível utilizar o **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.

## 🧩 Conceito do projeto

O projeto busca unir três áreas:

**Programação + Gamificação + Educação Financeira**

Em vez de apresentar apenas informações sobre dinheiro, a ideia é fazer o usuário **interagir com seus próprios objetivos**, visualizar seu progresso e aprender enquanto utiliza a aplicação.
